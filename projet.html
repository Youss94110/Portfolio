Mise en place d'un Active Directory avec GPO — Windows Server 2022

PLATEFORME · Windows Server 2022 OUTIL · VirtualBox DOMAINE · Active Directory (AD DS)

Mise en place d'un environnement Windows Server 2022 virtualisé avec VirtualBox, incluant la configuration d'un contrôleur de domaine Active Directory (AD DS) pour la gestion centralisée des utilisateurs et des groupes.

Des stratégies de groupe (GPO) ont été appliquées afin de renforcer la sécurité et restreindre certaines fonctionnalités côté client. Une machine Windows cliente a ensuite été intégrée au domaine pour valider le bon fonctionnement de l'infrastructure.

Ce projet illustre les bases de l'administration système, de la sécurité et de la gestion d'un réseau Windows en entreprise.

ÉTAPES CLÉS

  • Virtualisation du serveur (VirtualBox)
  • Installation d'AD DS
  • Configuration des GPO
  • Intégration d'un poste client au domaine
PROJETS RÉALISÉS 2025–2026 · Windows Server 2019 · Gestion des comptes utilisateurs via Active Directory · Configuration et administration des serveurs DNS et DHCP · Nettoyage, sécurisation et optimisation de l'Active Directory DS (mars–avril 2026)
